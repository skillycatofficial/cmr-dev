Technical SEO Checklist
● Fix Canonical Tags
Every page must have a self-referencing canonical. Fix all broken canonicals from the site audit
immediately. <link rel="canonical"
href="https://cmrdevelopers.com/projects/alvina-harmony-kannur/" />
● Image Optimisation
Convert all images to WebP. Add descriptive ALT text with location keywords. Compress to under
150KB per image. Example ALT: "Alvina Harmony luxury villa interior Chakkarakal Kannur Kerala"
● Mobile-First Speed
Target Core Web Vitals: LCP under 2.5s, CLS under 0.1, INP under 200ms. Most Kerala villa
buyers research on mobile. Target PageSpeed 85+.
● Schema Markup
Implement JSON-LD structured data on all key pages. Priority: LocalBusiness, RealEstateListing,
Review, FAQPage, JobPosting.
● XML Sitemap
Generate and submit sitemap.xml to Google Search Console. Include all project pages, blog posts,
and the new Careers page.
● HTTPS + RERA
Numbers
Enforce HTTPS site-wide with 301 redirect from HTTP. Display K-RERA registration numbers in
the footer on every page — legal requirement and trust signal.
● Google Business
Profile
Fully optimise GBP for "CMR Developers Taliparamba" and any project sales offices. Weekly posts
+ photo updates on GBP feed Maps rankings.
● Internal Linking
Every project page links to: Home, Projects Hub, NRI Page, Contact. Every blog post links to 2
project pages. Careers links to About. Minimum 3 internal links per page.
● Analytics & Tracking
GA4 + Google Search Console. Track: form submissions, WhatsApp clicks, phone taps, project
page scroll depth as conversion events via GTM.

WORDPRESS
WordPress Implementation Guide
Since cmrdevelopers.com is being built on WordPress, the following plugin stack and configuration
recommendations are essential. Each recommendation directly impacts SEO performance and maps to
specific pages in this plan.
1. SEO Plugin — Rank Math Pro (Recommended over Yoast)
Install Rank Math Pro — it supports RealEstate schema natively, unlike Yoast's free tier
Set up Schema type for each page: Home → WebSite + Organization, Project pages → RealEstateListing, Blog → Article, Careers →
JobPosting
Enable Rank Math's "Local SEO" module — auto-generates LocalBusiness schema with NAP and geo coordinates
Connect Rank Math to Google Search Console from Day 1 — gives keyword position data directly in WP dashboard
Configure the title tag templates: %title% | CMR Developers Kerala — applied site-wide automatically
Enable XML Sitemap in Rank Math and submit the sitemap URL to GSC immediately after launch
2. Page Builder — Elementor Pro (Or Bricks Builder)
Use Elementor Pro for project pages — its dynamic content fields make updating RERA numbers, prices and specs easy without
developer help
Create a "Project Page Template" in Elementor — apply it to Alvina, Aiza and Aina. Consistent structure also helps Google
understand your content pattern
Use Elementor's "Loop Grid" widget for the /projects hub page — dynamically pulls from Custom Post Types
Set up a "Villa Project" Custom Post Type (CPT) using CPT UI plugin — each project as a CPT post. This makes adding future
projects easy and SEO-friendly
Build the Google Maps embed as an Elementor widget using the Maps widget — no API key required for basic embeds
3. Speed & Core Web Vitals — Critical for SEO
WP Rocket (paid) or LiteSpeed Cache (free if on LiteSpeed server) — enable page caching, CSS/JS minification, lazy image loading
Smush Pro or ShortPixel — auto-compress and convert all uploaded images to WebP format. Essential for project page photo
galleries
Cloudflare (free tier) — adds CDN layer. Dramatically improves load speed for NRI visitors accessing from Gulf/UK/USA
Disable unused WordPress plugins — each plugin adds HTTP requests. Audit and deactivate anything not in active use
Use a lightweight theme: GeneratePress or Kadence — avoid bloated themes like Divi or Avada for better Core Web Vitals scores
Set up object caching via Redis if your hosting supports it — benefits the /projects hub page with many dynamic queries

Wordfence or Sucuri Security — real estate websites are targeted by spam form submissions. Protect all contact forms

UpdraftPlus — automated daily backups to Google Drive. One bad plugin update should not kill the site before a campaign launch
Disable WordPress XML-RPC if not used — common attack vector. Add to functions.php: add_filter('xmlrpc_enabled',
